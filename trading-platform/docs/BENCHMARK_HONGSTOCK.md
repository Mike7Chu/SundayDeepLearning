# 벤치마킹 요구사항 — HONG STOCK 앱 분석 (2026-08-26)

> 사용자가 제공한 참고 앱 'HONG STOCK'(별개 서비스 — 뉴스 분석에 Groq→Gemini 2단계 사용)
> 스크린샷 9장을 분석해, 우리 시스템(STOCKLAB)에 **벤치마킹 가능한 기능**을 요구사항으로 정리.
> 우리와 겹치는 건 제외하고, **우리에 없거나 더 나은 것** 위주.

## 관찰된 화면
1. 홈 — 최신 TOP3(분석 순위) + 최근 장 분석 + **종목선정 퍼널**(2,700+ → 30 → 3 → 3) + TOP30
2. 종목 상세 — 종목선정점수·매수판단·**쉬운 차트 근거**(추세/거래량/지지·저항 평문) + **캔들 차트 토글**
3. 분석 근거 — **축별 반영 점수**(기술 44.0/거래량/수급 15.3/뉴스 4.5/재무 13.5) 드릴다운 + 최신 뉴스
4~8. 축별 모달 — 기술적/거래량/수급/뉴스·이슈/재무 각각 "반영 점수 + 세부 근거" 팝업
9. 종합 분석 — 전 축 합산 요약 + '이 종목 모의 주문' + 면책

## 벤치마킹 요구사항 (우선순위)

### R1. 종목선정 퍼널 시각화 (홈) — ⭐ 높음 · 쉬움
- HONG: `전체 시장 2,700+ → 분석 대상 30 → 정밀 분석 3 → 분석 후보 3` 단계 카드(화살표 연결).
- 우리: 엔진 로그(`후보 241 → 검증대기 0 → 매수리스트 1`)엔 있으나 **홈에 시각화 없음**.
- 요구: 홈에 '오늘의 선별 과정' 퍼널 카드. 데이터는 `/engine`(buylist)·`/plan`·`stage1`
  카운트에서 이미 산출됨 → **API 노출 + 프런트 카드만 추가**(신규 계산 없음).

### R2. 점수 축별 분해 + 드릴다운 (종목 상세) — ⭐ 높음 · 중간
- HONG: 총점(77.3)을 **기술 44.0 / 거래량 / 수급 15.3 / 뉴스 4.5 / 재무 13.5**로 쪼개
  각 항목 탭 → "반영 점수 + 세부 근거"(예 RSI 55.12·20일 +25.4%·외인 +251만주) 팝업.
- 우리: `compute_score`가 총점만 노출. **축별 기여도·세부 근거 팝업 없음**.
- 요구: `compute_score`가 축별 부분점수(technical/volume/flow/news/financial)와 근거 문자열을
  함께 반환 → 모달에 '분석 근거' 아코디언(탭하면 세부값). **핵심 = 점수의 투명성/설명가능성**.

### R3. '쉬운 차트 근거' 평문 카드 (종목 상세) — ⭐ 높음 · 쉬움
- HONG: `추세: 이동평균선 혼조·방향 확인 필요 / 거래량: 평균 0.7배·약함 / 지지 187,308~191,092
  / 저항 285,120~290,880 / "가격 대비 거래량 부족"` — 초보도 읽는 **평문 해석**.
- 우리: `trade_levels`(진입/손절/목표)·시그널 값은 있으나 **평문 해석 카드 없음**.
- 요구: 기존 시그널/레벨에서 파생한 순수함수 `plain_chart_read(candles)` →
  {추세, 거래량, 지지구간, 저항구간, 한줄}. 신규 데이터 불필요, 표현만 추가.

### R4. 뉴스·이슈 감성 점수화 (스코어 축) — ⭐ 중간 · 중간(비용 주의)
- HONG: 최근 24h 뉴스 N건을 **감성 분석 → 점수(4.5점)로 선정점수에 반영**. 2단계 LLM.
- 우리: DART 공시/뉴스 목록은 있으나 **감성 점수화·선정점수 반영 없음**(리서치는 별도 전문).
- 요구: 종목별 최근 뉴스 헤드라인을 가볍게 감성 스코어(-1~+1)로 요약 → 점수 축 편입.
  ⚠️ 매 종목 LLM 호출은 토큰 과다 → **관심종목만·6~12h 캐시·온디맨드** 또는 규칙기반
  1차(키워드) + 필요 시 LLM. (우리는 Claude 사용 — Groq/Gemini 불필요.)

### R5. '분석 순위 ≠ 매수 추천' 명시 UX — ⭐ 중간 · 쉬움
- HONG: "분석 순위와 실제 매수 추천을 구분해 표시" + 각 종목 '매수 대기/매수' 배지.
- 우리: score·verdict는 있으나 **"높은 점수 = 지금 사라 아님"** 메시지가 약함.
- 요구: 홈·리스트에서 '분석점수'(관심도)와 '매수판단'(지금 살까) 배지를 시각적으로 분리·라벨링.
  우리 진입 규율(눌림목/과확장)과 자연스럽게 연결.

### R6. 캔들 차트 네이티브 토글 (종목 상세) — 🟡 낮음 · 중간
- HONG: 1/5/15/60분·일 + 꺾은선/봉차트 토글(경량 네이티브).
- 우리: TradingView 임베드(고급) + 실시간 라인. **봉차트 네이티브 토글은 없음**.
- 요구(선택): 저부담이면 상세 모달에 경량 봉차트 옵션. TradingView로 충분하면 스킵.

### R7. 기준시점 표기 일관화 — ✅ 이미 우리도 함(강화만)
- HONG: 모든 값에 '기준일 2026-08-26', '최근 24시간 확인' 등 시점 표기.
- 우리: 데이터 신선도 배지 이미 있음. 분석 근거/뉴스에도 동일 규율 확대 적용만.

## 권장 순서
1. **R1 퍼널 카드**(즉효·저비용) → 2. **R2 축별 분해**(설명가능성) →
3. **R3 평문 카드**(초보 친화) → 4. **R5 순위/추천 분리 UX** →
5. R4 뉴스 감성(비용 설계 후) → 6. R6 봉차트(선택).

> 원칙: 신규 LLM 호출을 늘리지 않는 R1~R3·R5부터. 토큰 드는 R4는 캐시·온디맨드로 최소화.
